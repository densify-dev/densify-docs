## Initiating Cloud Data Collection

You can collect and analyze data from your public cloud environments. You can configure a connection from Kubex to your cloud-hosted environments through the cloud connection wizard or through the Kubex API.



<InlineImageWithText width={50} href="/docs/WebHelp_Densify_Cloud/Content/Data_Collection_for_Public_Cloud_Systems/AWS_Data_Collection_Using_a_CloudFormation_Template" src="/images/docs-kubex/Content/Cloudex/03000165.png">
  Review the connection prerequisites to configure a user account that can then be used to create a connection Kubex:

  <ul>
    <li>
      <a href="/docs/WebHelp_Densify_Cloud/Content/Data_Collection_for_Public_Cloud_Systems/AWS_Data_Collection_Using_a_CloudFormation_Template"> AWS Data Collection Using a CloudFormation Template </a>
      --It is recommended to use the CloudFormation template as it automates the entire process.
    </li>
    <li>
      <a href="/docs/WebHelp_Densify_Cloud/Content/Data_Collection_for_Public_Cloud_Systems/AWS_Data_Collection_Prerequisites_for_an_IAM_Role__CloudWatch_only_"> AWS Data Collection Prerequisites for an IAM Role (CloudWatch only) </a>
      --Use this version if you need to customize access permissions for memory metrics.
    </li>
    <li>
      You can also connect your AWS accounts to Cloudex by using the <a href="/docs-kubex/Content/Cloudex/Data_Collection_AWS_Connections"> cloud connection wizard </a>
    </li>
  </ul>
</InlineImageWithText>
