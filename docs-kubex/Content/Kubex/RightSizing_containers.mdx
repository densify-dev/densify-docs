## Rightsizing Containers

Container rightsizing is critical for both cost efficiency and runtime stability.

| Risk Type | Risk Details |
| --- | --- |
| Oversized containers | Reserve more CPU or memory than workloads actually use, which can cause infrastructure cost waste from idle reserved capacity, reduced cluster utilization, higher probability of pending pods, failed deployments due to resource fragmentation, and autoscaler thrashing from inefficient scheduling pressure. |
| Undersized containers | Create performance and reliability risk because workloads do not receive enough resources to run safely. |
| Undersized memory limits | Can cause OOM kills. |
| Undersized CPU limits | Can cause throttling and degraded application performance. |
| Undersized requests | Can cause node overcommitment, leading to unstable scheduling behavior and capacity contention. |

## Recommended Action

Apply Kubex recommendations for containers to align requests and limits with real usage patterns.

For the most efficient and hands-off execution path, use Kubex automation to apply approved recommendations consistently at scale.
