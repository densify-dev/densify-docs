## Installation

The Automation Engine is installed as part of the Kubex Automation Stack. If the stack is not installed yet, follow the [Data Collection Overview](/docs-kubex/Content/Kubex/Data_Collection_Overview) installation steps and add `--set kubex-automation-engine.enabled=true` to the stack's Helm install command.

If the stack is already installed with the Automation Engine disabled, enable it on the existing release with:

```bash
helm upgrade kubex kubex/kubex-automation-stack \
  --namespace kubex \
  --reset-then-reuse-values \
  --set kubex-automation-engine.enabled=true
```

The `--reset-then-reuse-values` option preserves the existing release values while applying the current chart defaults and the Automation Engine override.

## Verify Health

```bash
kubectl get deployment kubex-automation-engine -n kubex
kubectl get pods -n kubex -l control-plane=controller-manager
kubectl get validatingwebhookconfigurations,mutatingwebhookconfigurations | grep kubex
```

## Create First Strategy and Policy

You can either:

- Manage strategy and policy CR manifests directly with `kubectl` or GitOps

Also validate:

- Policy resolution in controller logs
- Recommendation ingestion and rightsizing application for targeted workloads

## Uninstall Notes

When uninstalling, remove the stack resources and clean up any remaining finalizers for externally managed CRs.
