The Container Explorer is used to navigate through your containers and select the scope you want to review.

<Frame caption="Figure: Kubex Dashboard">
![](/images/docs-kubex/Content/Kubex/container_explorer.png)
</Frame>


## Select a Container Scope

The **All Containers** filter displays all containers in the environment. Select a user-created filter to narrow the scope to the containers that are relevant to your current task.

You can create filters based on the available container attributes and reuse them whenever you need to review the same scope. A filter can be set as your **default filter**. When a default filter is configured, it replaces the **All Containers** filter as the starting scope in the Container Explorer.

## Navigate the Container Tree

Use the tree view to further navigate within the selected scope. The tree is collapsed by default so that you can start with a focused view, then expand the hierarchy to move through the containers and the groups that contain them.

The selected scope controls the container data displayed in the related analysis and optimization views. Change the filter or expand the tree to move from an environment-wide view to the specific containers you want to investigate.
