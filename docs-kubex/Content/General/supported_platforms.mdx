## Public Cloud Platforms

Kubex optimizes infrastructure across all major cloud providers:

- AWS: EC2, RDS, Auto Scaling Groups (Available)
- Azure: Virtual Machines, Scale Sets (Available)
- Google Cloud: Compute Engine instances (Available)
- Oracle Cloud: OCI Compute instances (Coming Feb 2026)
- Amazon ECS: Elastic Container Service (Available)

## Observability & Monitoring Integrations

Kubex augments optimization analysis by integrating with leading observability platforms:

- Prometheus: Ingest Kubernetes metrics for optimization analysis
- Datadog: Collect monitoring and observability data
- New Relic: Collect monitoring and observability data
- Grafana: Visualize and explore metrics used by Kubex
- OpenTelemetry: Collect distributed traces, metrics, and logs
- DCGM Exporter: NVIDIA GPU performance and utilization metrics

## Process Automation Integrations

Kubex integrates with ticketing and infrastructure-as-code platforms:

- JIRA: Automate optimization ticket creation and management
- ServiceNow: Automate optimization ticket creation and management
- Terraform: Align infrastructure as code with optimization outputs

## Deployment and Orchestration

- Helm: Deploy and manage Kubex components via Helm charts
- Karpenter: Optimize Kubernetes node provisioning and scaling

## AI and Advanced Capabilities

- MCP Server: Provide secure and structured access to optimization data for AI agents
