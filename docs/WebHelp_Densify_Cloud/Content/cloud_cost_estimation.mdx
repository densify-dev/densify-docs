---
title: Cloud Cost Estimation
description: Understand how Kubex estimates cloud instance costs from provider list prices and optional billing data.
---

Kubex estimates cloud costs using CSP list prices based on the instance type, region, and software on the instance (such as Linux, Windows, or SQL Server). Instance uptime is also considered to provide accurate cost estimates.

## Enterprise Discounts

Enterprise discounts can be applied across all instances or scoped to a specific criteria, such as a defined set of accounts. Contact your account team to provide details of discounts in your cloud environment.

## Billing Data Integration

Kubex can also integrate with your billing data to produce more accurate instance costs that better reflect your bill and account for RIs, SPs, and enterprise discounts.

This integration is not enabled by default because it requires additional permissions to access billing data. Contact your account team to have it set up.
