The Kubex API is a REST-based web service that is designed for the following:

* Kubernetes Container Recommendations
* AWS - Onboard new accounts and retrieve Kubex right-sizing recommendations
* Azure - Onboard new subscriptions and retrieve Kubex right-sizing recommendations
* GCP - Onboard new projects and retrieve Kubex right-sizing recommendations
* Catalog Map - Get a list of how all instance types scored for a given instance 
* Analysis webhook
* Subscriptions (customizable analysis results API)
